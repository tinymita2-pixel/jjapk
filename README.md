# 짭크

마인크래프트 자바 서버에 휴대폰으로 붙어서 채팅하는 안드로이드 앱이에요. 배터리를 적게 쓰도록 처음부터 만들었어요.

**NOT AN OFFICIAL MINECRAFT PRODUCT. NOT APPROVED BY OR ASSOCIATED WITH MOJANG OR MICROSOFT.**
마인크래프트 공식 앱이 아니며 Mojang, Microsoft 와 관계없어요.

## 받기

- **[최신판 APK 받기](https://github.com/tinymita2-pixel/jjapk/releases/latest/download/jjapk.apk)** (이 링크는 늘 최신판을 받아요)
- 안드로이드 8.0 이상. 설치할 때 "출처를 알 수 없는 앱" 허용이 필요해요.
- 새 버전이 나오면 앱 홈 화면 위에 알림이 떠요.
- 서명 인증서 SHA-256: `77e69a58bf323cdbc953b1f557e5dbb6319fa5689412cb5fc027456954bfc327`

## 되는 것

- 서버 버전 1.21.1 ~ 26.3 (자동 감지), 복돌 계정과 정품(마이크로소프트) 계정, 서버 이동(transfer)
- 채팅과 명령, Tab 키 자동완성, 채팅 검색, 대화 기록 저장, 같은 메시지 합치기, 채팅 숨김, 키워드 알림
- 서버별 클라이언트 이름(브랜드), 서버에 보이는 렌더 거리, 서버에 보내는 언어
- 링크 미리보기: imgur 이미지와 앨범, YouTube 썸네일, X. 채팅 속 또는 팝업, 크게 보기, 저장
- CinemaMod 서버의 영상 같이 보기 (대기열 투표, 기록)
- 메모 판 (채팅을 왼쪽으로 밀기): 누르면 복사, 입력칸에 넣기
- 접속자 목록과 스킨 머리, 연결 상태 (받은 양, 보낸 양, 지연)
- 앱 화면 한국어, English

## 배터리

움직이기, 인벤토리, 지형 해석을 하지 않아요. 서버가 보낸 것에만 답하고 웨이크락을 잡지 않아요.
화면이 꺼져 있으면 이미지와 영상을 받지 않아요. 휴대폰이 화면을 끈 뒤 연결을 끊으면, 앱 설정 맨 아래 배터리 항목의 "허용"을 눌러 주세요.

## 알아 둘 것

- **정품 로그인**은 공식 마인크래프트 런처의 공개 로그인 ID 를 빌려 쓰는 비공식 방식이에요. 로그인은 마이크로소프트 공식 페이지에서 직접 하고, 앱은 비밀번호를 보지 않아요. 마이크로소프트가 이 방식을 막으면 정품 로그인이 안 될 수 있어요.
- **리소스팩** 요청에는 받았다고 답하고 실제로는 받지 않아요. **클라이언트 이름**도 바꿀 수 있어요. 봇이나 다른 클라이언트를 막는 서버에서는 차단될 수 있으니 서버 규칙을 확인하세요.
- **데이터가 가는 곳**: 로그인은 마이크로소프트, Xbox, Mojang. 언어 파일과 스킨은 Mojang. 링크 미리보기는 imgur, fxtwitter, YouTube. 새 버전 확인은 GitHub (설정에서 끌 수 있음). 광고와 통계 수집은 없어요. 계정 정보는 기기 키로 암호화해서 휴대폰에만 저장해요.

- 영상 같이 보기는 CinemaMod 서버와 통신 형식을 맞췄어요.
